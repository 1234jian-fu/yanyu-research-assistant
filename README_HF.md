# 研语·工科科研助手 v4.0

> 双引擎架构 · 15+功能矩阵 · 零篡位执行 · 影子写作 · 确定性格式对齐

## 双引擎页面

### ✍️ 论文内容写作
- 📝 **中转英翻译**：中英双向精准学术翻译，严格跨语种输出并保留术语、LaTeX 与公式
- ✨ **表达润色**：提升学术地道性，同语言优化，不跨语种改写
- 🔍 **逻辑检查**：检查因果链条、衔接关系与术语一致性，不直接改文
- 🤖 **去AI味 (Humanizer)**：同语言重构，消除 AI 模板感，增强真人写作节奏
- ✍️ **影子写作 / 逐段起草**：优先模仿标杆文献的叙事节奏进行内容生成
- 🎯 **精修模式 / Redlining**：生成修订建议并支持 Word 导出

### 📏 确定性格式对齐
- 📐 **格式指南解析**：读取学校/课题组排版要求并提炼为结构化规则
- 📄 **Word 审查**：检查标题、正文、行距、页眉页脚、参考文献等格式问题
- ✅ **勾选式修复**：只对用户勾选的样式项执行确定性修改
- 📥 **Word 导出**：输出修复后的 `.docx`
- 🔒 **安全边界**：不改正文逻辑、不翻译内容、不触碰公式语义
