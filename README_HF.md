# 研语·工科科研助手 v4.0

> 15+功能矩阵 · 板块锚定 · 零篡位执行 · 影子合著者 · 语言基因深度提取

## 功能列表

### 核心功能
- 📝 **中转英翻译**：中英双向学术翻译，执行跨语种转换并保留术语、LaTeX 与公式
- ✨ **表达润色**：提升学术地道性，同语言优化，不跨语种改写
- 🔍 **逻辑检查**：检查因果链条、衔接关系与术语一致性，不直接改文
- 🤖 **去AI味 (Humanizer)**：同语言重构，消除 AI 模板感，增强真人写作节奏
- 👨‍⚖️ **Reviewer视角**：模拟审稿人视角审视论证强度、表达清晰度与潜在问题
- ✍️ **逐段起草**：将大纲扩充为正式段落，并对齐当前论文板块写法
- 🎯 **精修模式**：深度精修，提升到顶刊级表达水准
- 📋 **Redlining修订**：生成带修订痕迹的修改建议，支持 Word 导出

### 辅助功能
- 💡 研究想法构思：围绕当前领域生成可落地的研究方向与创新点
- 🧠 ML论文写作（NeurIPS/ICML级别）：强化 Results / 图表 / 引用 / checklist 约束
- 📊 概念图设计：生成论文概念图与图示设计思路
- 📄 节节头脑风暴：围绕当前板块提供结构化思路拓展
- 📝 引用验证：检查引用格式、完整性与相关性
- 🎨 图表规范检查：检查图表描述、色盲友好性与标注规范
- 🔄 版本对比：对比不同版本文本的差异与修改说明
